# Annals of Scrivenearth

An original hero-driven card battler for the browser. Command a Spire in a city of cut crystal, field units and
glyphs from two of six factions, and build toward the moment your heroes **Ascend**. One player against an AI.

- Play: https://dragoonant.github.io/annals-of-scrivenearth/ (once Pages is enabled; see `PLAN.md`)
- Rules: `docs/spec/10-rules.md` · Decisions: `PLAN.md` · State of the build: `STATUS.md`

```
npm install
npm run dev        # play locally
npm test           # rules, heroes, one behaviour test per card, sims
npm run sim -- --games 100 --a normal --b random
```

Unofficial, non-commercial, original fan-made game. See `NOTICE.md`.
